# Training Set Platform: Web App (`apps/web`)

Next.js 16 (static export), styled with a copy of the UI canvas styles (`src/ui/kit.css`; what
differs from the canvas is in [docs/ui-gaps.md](../../docs/ui-gaps.md)). Pages talk to the backend only through
`src/backend-api/`, which also wires all apps together; everything runs in the browser during the
MVP (see [docs/handover/integration.md](../../docs/handover/integration.md)).

From the repo root:

```bash
npm ci
npm run dev          # http://localhost:3000
npm run check        # typecheck, unit tests, boundary check
npm run build        # static site in apps/web/out/
node apps/web/scripts/e2e-check.cjs http://localhost:4173   # browser check against a served build
```

Build-time settings (none are secret, and none may be):

| Variable | Meaning |
|---|---|
| `NEXT_PUBLIC_BASE_PATH` | Sub-path the site is served under, for example `/training-set` |
| `NEXT_PUBLIC_EXAMPLES_URL` | URL of the prepared examples file. Default: the synthetic sample in `public/sample-data/` |
| `TSP_PLATFORM_IMPL` | Module behind `@tsp/platform-impl`, relative to the repo root. Default: the stand-ins |

The sample data in `public/sample-data/` is synthetic (generated by `scripts/make_sample_data.py`).
Real examples never go in this repository.
