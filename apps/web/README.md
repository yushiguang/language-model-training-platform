# Sprint: Web App (`apps/web`)

Next.js 16 (static export) on Astryx with the Sprint theme (Neutral, black accent, indigo only for
AI). The app shell (top bar, steps, Ask AI panel, page, dialogs, the access dialog) is in
`src/components/Shell.tsx` and `src/components/shell/`. Pages not yet moved to Astryx still use the
old kit (`src/ui/kit.css`, in the `legacy` CSS layer; what differs from the canvas is in
[docs/ui-gaps.md](../../docs/ui-gaps.md)). Pages talk to the backend only through
`src/backend-api/`, which also wires all apps together; everything runs in the browser during the
MVP (see [docs/integration.md](../../docs/integration.md)).

From the repo root:

```bash
npm ci
npm run dev          # http://localhost:3000
npm run check        # typecheck, unit tests, boundary check
npm run build        # static site in apps/web/out/
node apps/web/scripts/e2e-check.cjs http://localhost:4173   # browser check against a served build
```

Build-time settings (none are secret, and none may be):

| Variable | Meaning |
|---|---|
| `NEXT_PUBLIC_BASE_PATH` | Sub-path the site is served under, for example `/training-set` |
| `NEXT_PUBLIC_EXAMPLES_URL` | URL of the prepared examples file. Default: the synthetic sample in `public/sample-data/` |
| `SPRINT_PLATFORM_IMPL` | Module behind `@yushiguang/sprint-platform-impl`, relative to the repo root. Default: the stand-ins |
| `SPRINT_CLIENT_IMPL` | Module behind `@yushiguang/sprint-client-impl` (exports `client: BffClient`), relative to the repo root. Default: `apps/web/src/backend-api/in-process.ts`, every service in the page |

The sample data in `public/sample-data/` is synthetic (generated by `scripts/make_sample_data.py`).
Real examples never go in this repository.
