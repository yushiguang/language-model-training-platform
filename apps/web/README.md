# Training Set Platform: Web App (`apps/web`)

Next.js 16 (static export) + Astryx Neutral + ECharts. Communicates with the backend exclusively
through `src/backend-api/` (`@tsp/contracts/bff-api`) and runs in the browser during the MVP
(see [docs/handover/integration.md](../../docs/handover/integration.md)).

```bash
cd apps/web
npm ci
npm run dev          # http://localhost:3000
npm run typecheck    # typechecks web, agents, bff, contracts, and infra
npm test             # runs unit tests across contracts, agents, and bff
npm run build        # writes static site to apps/web/out/
```

Build-time settings (none are secret, and none may be):

| Variable | Meaning |
|---|---|
| `NEXT_PUBLIC_BASE_PATH` | Sub-path the site is served under, for example `/training-set` |
| `NEXT_PUBLIC_EXAMPLES_URL` | URL of the prepared examples file. Default: the synthetic sample in `public/sample-data/` |

The sample data in `public/sample-data/` is synthetic (generated by `scripts/make_sample_data.py`).
Real examples never go in this repository.
