## Major (for the External Agent)

- `apps/bff/src/services/work.ts:92` + `apps/bff/src/services/optimiser.ts:42` — cross-tab
  duplicate optimiser: `once('optimiser')` is a per-page in-memory set, and `runOptimiser`
  inserts a new run without checking for an already-running run on that endpoint. Two tabs can
  each pay for up to 6 candidates; with the caps and the 120% pause removed in `ba21715` there
  is no cost backstop left. (Score/resume are safe: task reuse plus the labeling lock.)
- `apps/web/src/app/dataset/page.tsx:22` — the header Next button approves with the last saved
  split while split edits autosave after 400 ms; clicking Next within that window (or with
  invalid sizes visible) advances on stale numbers and discards the pending edit.
- `apps/web/src/app/gold/page.tsx:90` + save at `:259` — `YourAnswer` autosaves after 300 ms
  and is keyed per example; pressing Previous/Next inside that window unmounts it and the
  pending save is cleared, silently losing the label. The old flow saved before moving.
- `apps/web/src/app/gold/page.tsx` (saveGold call) — `modelShown` (default true) is recorded
  even when no model answer exists, so labels are stored as model-revealed when the user never
  saw an answer; this corrupts the stored label and the `gold_label_saved` telemetry.
- `apps/web/src/app/gold/page.tsx` (`ModelAnswer`) — `if (!found) return null` conflates
  "still loading" with "no answer": the card disappears during lookup and pops in later.
- `apps/web/src/app/setup/page.tsx:70` — an open schema draft can never be discarded: `dirty`
  excludes drafts, the proposal card offers only Approve, and Next stays disabled while a
  draft is open; a user who rejects an agent draft is stuck.
- `apps/web/src/app/setup/page.tsx:84` — Approve saves the whole draft schema, but the page
  renders only fields; the schema `policy` is never shown or editable (it was before), so
  users approve policy text they cannot see.
- `apps/web/src/app/training-set/page.tsx:9` — the "Finish project" flow is gone: nothing
  calls `approveNode(..., 'training')`, projects never reach the finished state, and the
  `project_finished` event never fires.
- `docs/ui-gaps.md:40` — "Ask AI stays open when moving between Prompt Engineering pages" is
  false: open state is per-page (`Shell.tsx`), and navigation remounts it closed.

## Media on Gold Labels (done internally, by request)

Researched playback model: the platform hands out no playable video file. The item's official
embed player (iframe by item id) is the primary channel for videos and photo posts, still
images come from public image URLs, and an internal viewer is the fallback when an item is no
longer publicly playable.

- Kept: the `Platform.media?: MediaSource` seam and the bff `exampleMedia` passthrough.
- Contract change `0d98329`: `ExampleMedia.videoUrl` is `playerUrl` — the URL of the player
  page to embed. The adapter owns player choice and availability probing.
- `0a31895`: the Gold Labels example card embeds `playerUrl`, shows the cover/still images
  as a switchable strip, and keeps the item id visible (the browser check reads it).
- The internal adapter (internal overlay, not in this repo) returns the official embed player
  for numeric ids, probes availability through the public oEmbed endpoint, falls back to the
  internal viewer, and takes still images from the prepared examples file.
