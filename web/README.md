# Training Set Platform: MVP web app

Next.js 16 (static export) + Astryx Neutral + ECharts. Runs fully in the browser on stand-in
services until the hosting platform's runtimes are connected
(see [docs/handover/integration.md](../docs/handover/integration.md)).

```
npm ci
npm run dev          # http://localhost:3000
npm run typecheck
npm test             # unit tests for src/core
npm run build        # static site in out/
npm run schema       # regenerate ../db/schema.sql from src/data/schema.ts
```

Build-time settings (none are secret, and none may be):

| Variable | Meaning |
|---|---|
| `NEXT_PUBLIC_BASE_PATH` | Sub-path the site is served under, for example `/training-set` |
| `NEXT_PUBLIC_EXAMPLES_URL` | URL of the prepared examples file. Default: the made-up sample in `public/sample-data/` |

The sample data in `public/sample-data/` is made up (generated by `scripts/make_sample_data.py`).
Real examples never go in this repo.
